# MeatZ – Premium Quality Meat E-Commerce Website

A modern and responsive meat delivery website built using **HTML, CSS, and JavaScript**.
MeatZ provides a premium online shopping experience for fresh meat products like chicken, mutton, fish, prawns, and more. The website includes an attractive UI, shopping cart functionality, wishlist feature, animations, and responsive design. 

---

## 🚀 Features

* 🛒 Add to Cart functionality
* ❤️ Wishlist system
* 📱 Fully Responsive Design
* 🎨 Modern Premium UI/UX
* ⚡ Smooth animations and transitions
* 🔍 Search bar interface
* 🥩 Product categories section
* 🚚 Fast delivery themed design
* ⭐ Customer reviews section
* 📦 Interactive cart drawer
* 🔔 Toast notifications
* 🌙 Dark theme premium layout

---

## 🛠️ Technologies Used
